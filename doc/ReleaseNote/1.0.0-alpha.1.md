# RunBay 1.0.0-alpha.1

Date: 2026-10-24

## Summary
The first public alpha of RunBay: register apps, run their Build / Run / Build + Run
and custom PowerShell actions, and follow their live, colored output in a Full
window, a Compact list, or a floating icon. Coding agents can use RunBay through
MCP (`RunBay.exe --mcp`), and RunBay updates itself from GitHub Releases.

## New features
- Apps with icons, groups, working directory, environment variables, and a script
  editor; custom actions; per-action `whenRunning` rules and history retention.
- Runs in Windows Job Objects: Stop ends the whole process tree; a run lasts while
  the started application lives.
- Live ANSI-colored output with tabs, Copy, Open log, and an Action History with
  filters.
- Full, Compact, and Icon modes with always on top, remembered positions, the
  system tray, and load with Windows.
- MCP server over stdio with access levels (Off / Ask first / Unrestricted),
  confirmation dialogs, agent markers, and Undo for agent changes.
- Automatic updates with SHA-256 verification.

## Upgrade notes
- First release; nothing to migrate. Keep `RunBay.exe` in a folder you can write
  to: the `data/` folder is created next to it.

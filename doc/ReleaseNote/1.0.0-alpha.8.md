# RunBay 1.0.0-alpha.8

Date: 2026-10-25
Previous: 1.0.0-alpha.7

## Summary
Improve console scrollbar dragging and make dropdowns and action menus
consistent with Material 3 Expressive.

## Fixes
- Keep dropdown arrows in sync with popup visibility so they return to the
  closed position after selection, keyboard dismissal, or an outside click.
- Use shared Expressive menus for Settings, editor and History dropdowns and
  app action menus, with rounded surfaces, clear selected states, consistent
  targets, and keyboard navigation for choices.
- Execute Add action and overflow choices before dismissing their popups so
  the selected action is delivered reliably.
- Widen the vertical scrollbar drag target to a dedicated 20 px lane in Full
  and Compact/Icon console viewers, preventing accidental text selection.

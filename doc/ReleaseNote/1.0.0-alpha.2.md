# RunBay 1.0.0-alpha.2

Date: 2026-10-24
Previous: 1.0.0-alpha.1

## Summary
Everyday controls are easier to reach: every action appears as a direct icon
button with overflow handling, actions can use symbols or your own images, Stop
is available on app cards in every mode, and Settings is organized into
categories with a theme shortcut. Apps can keep only the actions they need.
Output text can be selected and copied, console colors have their own theme,
taskbar buttons can be hidden, and MCP setup instructions for Claude Desktop and
Codex can be copied from every mode.

## New features
- **Flexible app actions**: remove Build, Run, or Build + Run per app and
  restore missing defaults from Add action, alongside Custom action. All
  actions, including custom ones, appear directly as icon buttons in Full,
  Compact, and Icon; a three-dot menu holds only the actions that do not fit.
- **Action icons**: choose a Material Symbol for each standard or custom action
  in the app editor, independently of the app avatar, or reset it to the
  default. New symbols include Open folder, Code editor, IDE, Code blocks, and
  Data object. MCP `set_action` supports the same choice.
- **Custom action images**: use **Image…** in the app editor to give an action
  your own png, ico, or svg, such as the logo of the editor it opens. The image
  keeps its own colors on buttons and menus and is removed with the action.
  MCP `set_action_icon` sets or removes it.
- **Output text selection**: drag across colored output, Shift+click to extend,
  double-click a word, or triple-click a line. Use Ctrl+C / Ctrl+Insert to copy,
  Ctrl+A to select all, Shift+arrows / Home / End to extend, and Escape to
  clear. The same controls and right-click Copy / Select all menu work in the
  Full panel and Compact/Icon output popups. Selecting pauses auto-scroll;
  dragging beyond the view scrolls to more output. Copies are plain text with
  Windows line endings.
- **Console theme**: an output header icon button cycles Follow UI, Light, and
  Dark independently of the application theme. The choice is saved, shared by
  the Full and Compact/Icon consoles, and also available in Settings >
  Appearance and as the MCP `console_theme` option. Text, ANSI colors, and
  selection colors update immediately without losing the selection or scroll
  position.
- **Theme shortcut**: a single icon button beside the RunBay title cycles
  System, Light, and Dark themes, with distinct Auto, Sun, and Moon icons.
- **Organized Settings**: categories for Appearance, Startup & data, Action
  defaults, Updates, and Agents, with a clear Back button and an explanation
  that changes are saved automatically.
- **Taskbar icon setting**: Settings > Appearance can hide the taskbar button of
  the Full and Compact windows separately; the tray icon keeps RunBay reachable.
  Also available through MCP `update_settings`.
- **Copy MCP setup instructions**: copy a ready-to-paste guide for Claude
  Desktop or Codex from Settings > Agents, the Compact window, or the Icon popup
  and right-click menu. It includes this RunBay executable's path, any
  `--data-dir` arguments, client configuration examples, and connection checks,
  and confirms when copied.

## Fixes
- Keep More and other icon buttons square instead of stretching into wide pills,
  with centered symbols in Full, Compact, and Icon modes.
- Use consistent icon-only Build, Run, Build + Run, and custom action controls
  with matching icon sizes, button backgrounds, and name tooltips.
- Explain status badges on hover, including which action last succeeded,
  failed, or stopped.
- Expose Stop directly on app cards in every mode, including parallel actions.
- Restore live Windows theme tracking when switching back to System.

## Upgrade notes
- Apps with removed standard actions require this version or newer; earlier
  releases require Build, Run, and Build + Run to remain configured.
- Custom action images are ignored by earlier releases, which show the action's
  symbol instead.

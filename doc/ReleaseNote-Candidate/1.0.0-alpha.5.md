# RunBay 1.0.0-alpha.5

Date: 2026-10-25
Previous: 1.0.0-alpha.4

## Summary

Fix duplicate window title bars on startup, improve switch contrast, and add
direct theme switching in a wider Compact window.

## New features

- Add a theme button to Compact, sharing Full's System / Light / Dark preference.

## Fixes

- Apply custom captions and saved taskbar settings as soon as the native window
  is ready, so Full and Compact start with a single title bar without requiring
  a Settings change. Restore saved Full maximization after frame initialization.
- Use contrasting RunBay theme colors for Settings switches, including a light
  thumb on the selected track in Light mode.
- Increase Compact's default and minimum width to 360 px so its theme button,
  caption controls, and connected-agent indicator fit together.

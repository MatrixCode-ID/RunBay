# RunBay 1.0.0-alpha.7

Date: TBD
Previous: 1.0.0-alpha.6

## Summary

Settings, Action History, and the app editor receive a Material 3 Expressive
pass with clearer groups, connected retention controls, reliable navigation,
easier console scrolling, and app reordering from the app icon.

## New features

- Keyboard navigation and visible focus indicators for shared buttons, Settings
  navigation, editor actions, and Action History; Enter/Space activate controls,
  and Up/Down selects categories and history entries.
- Settings groups use segmented lists, responsive trailing controls, a constrained
  content column, and explanations for each MCP access level. Retention uses
  Off / Last N / Forever connected buttons in Settings and the app editor.
- Action History uses status/source filter chips with a selected check icon in
  a wider panel, keeping app/action dropdowns together.
- The three-column app editor has Script, Environment, and Behavior sections,
  consistent text fields, and clearer button emphasis. Compact and Icon action
  targets are 32 px.
- Drag an app icon to reorder cards within its group in Full, Compact, and the
  Icon app list. An insertion marker shows the destination, and the order is saved.

## Fixes

- Settings categories, editor actions, and History rows respond to the first
  mouse click without acquiring keyboard focus.
- Editor action selection keeps keyboard focus through repeated Up/Down presses
  and scrolls the selected action into view.
- Console horizontal scrolling has a dedicated 20 px drag lane outside text
  selection, making the scrollbar easier to grab.
- Card header three-dot buttons stay aligned when an app shows an agent badge
  or a long name.

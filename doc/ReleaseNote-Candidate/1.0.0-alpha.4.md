# RunBay 1.0.0-alpha.4

Date: 2026-10-24
Previous: 1.0.0-alpha.3

## Summary
Full and Compact now use consistent custom title bars while retaining native
window resizing and snapping, including when their taskbar buttons are hidden.

## New features
- Add themed title bars to Full and Compact with Minimize and Close controls,
  plus Maximize/Restore and Windows 11 Snap Layouts support in Full.
- Minimize hides to the tray when that window's taskbar button is disabled,
  including system-menu Minimize and Win+Down. Compact no longer maximizes.

## Fixes
- Hiding the Full or Compact taskbar button keeps the regular window frame,
  shadow, and rounded corners instead of switching to a tool window caption.
- Keep Full and Compact eligible for zone-based window layout tools when the
  taskbar button is hidden by using a never-visible owner window.

# RunBay 1.0.0-alpha.3

Date: 2026-10-24
Previous: 1.0.0-alpha.2

## Summary
Runs now show how long they take: a live elapsed time while running and the
final duration afterwards, wherever runs appear.

## New features
- **Elapsed time**: run rows below each app, run tabs, the Output panel header,
  and the Compact/Icon output popup show a live elapsed time while a run is
  active and its final duration once it ends. The clock ticks only while runs
  are active, so an idle RunBay stays quiet.

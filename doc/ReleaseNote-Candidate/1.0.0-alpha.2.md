# RunBay 1.0.0-alpha.2

Date: 2026-10-24
Previous: 1.0.0-alpha.1

## Summary
Configurable action icons, direct Stop controls in every mode, a theme shortcut,
and categorized Settings make everyday controls easier to reach. Output text can
be selected and copied across colored lines in Full, Compact, and Icon modes.
Console themes can be selected independently of the UI theme, and the Full and
Compact taskbar buttons can be hidden.
MCP setup instructions for Claude Desktop and Codex can be copied in every mode.
Apps can keep only the actions they need, restore removed defaults, and show
custom actions directly with overflow handling.

## New features
- **Flexible app actions**: remove Build, Run, or Build + Run per app and restore
  missing default actions from Add action, alongside Custom action. All actions,
  including custom actions, appear directly as icon buttons in Full, Compact,
  and Icon; a three-dot menu contains only actions that do not fit. Folder-opening actions can use `folder_open`.
- **Console theme**: an output header icon button cycles Follow UI, Light, and
  Dark independently of the application theme. The choice is saved and shared
  across Full and Compact/Icon consoles, with a matching Appearance setting
  and MCP `console_theme` option. Existing text, ANSI colors, and selection
  colors update immediately without losing the selection or scroll position.
- **Copy MCP setup instructions**: copy a ready-to-paste guide for Claude Desktop
  or Codex from Settings > Agents, the Compact window, or the Icon/badge popup
  and right-click menu. It includes this RunBay executable's path, optional
  `--data-dir` arguments,
  client configuration examples, and connection checks, with confirmation when
  copied.
- **Taskbar icon setting**: Settings > Appearance can hide the taskbar button
  of the Full and Compact windows separately; the tray icon keeps RunBay
  reachable. Also available through MCP `update_settings`.
- **Output text selection**: drag across colored output, Shift+click to extend,
  double-click a word, or triple-click a line. Use Ctrl+C / Ctrl+Insert to copy,
  Ctrl+A to select all, Shift+arrows / Home / End to extend, and Escape to clear.
  The same controls and right-click Copy / Select all menu work in the Full
  panel and Compact/Icon output popups. Selecting pauses auto-scroll; dragging
  beyond the view scrolls to more output. Copies are plain text with Windows
  line endings.
- **Action icons**: choose a Material Symbol for each standard or custom action
  in the app editor, independently of the app avatar. Reset to its default at
  any time; MCP `set_action` supports the same choice.
- **Theme shortcut**: a single icon button beside the RunBay title cycles
  System, Light, and Dark themes, with distinct Auto, Sun, and Moon icons.
- **Organized Settings**: categories for Appearance, Startup & data, Action
  defaults, Updates, and Agents, with a clear Back button and automatic-save
  explanation.

## Fixes
- Keep More and other icon buttons square instead of stretching into wide pills;
  center their symbols in Full, Compact, and Icon modes.
- Use consistent icon-only Build, Run, Build + Run, and Custom action controls
  with matching icon sizes, button backgrounds, and name tooltips.
- Explain status badges on hover, including which action last succeeded, failed,
  or stopped.
- Expose Stop directly on app cards in every mode, including parallel actions.
- Restore live Windows theme tracking when switching back to System.

## Upgrade notes
- Apps with removed standard actions require this version or newer; earlier
  releases require Build, Run, and Build + Run to remain configured.

# RunBay 1.0.0-alpha.2

Date: 2026-10-24
Previous: 1.0.0-alpha.1

## Summary
Configurable action icons, direct Stop controls in every mode, a theme shortcut,
and categorized Settings make everyday controls easier to reach. Output text can
be selected and copied across colored lines in Full, Compact, and Icon modes.

## New features
- **Output text selection**: drag across colored output, Shift+click to extend,
  double-click a word, or triple-click a line. Use Ctrl+C / Ctrl+Insert to copy,
  Ctrl+A to select all, Shift+arrows / Home / End to extend, and Escape to clear.
  The same controls and right-click Copy / Select all menu work in the Full
  panel and Compact/Icon output popups. Selecting pauses auto-scroll; dragging
  beyond the view scrolls to more output. Copies are plain text with Windows
  line endings.
- **Action icons**: choose a Material Symbol for each standard or custom action
  in the app editor, independently of the app avatar. Reset to its default at
  any time; MCP `set_action` supports the same choice.
- **Theme shortcut**: a single icon button beside the RunBay title cycles
  System, Light, and Dark themes, with distinct Auto, Sun, and Moon icons.
- **Organized Settings**: categories for Appearance, Startup & data, Action
  defaults, Updates, and Agents, with a clear Back button and automatic-save
  explanation.

## Fixes
- Keep More and other icon buttons square instead of stretching into wide pills;
  center their symbols in Full, Compact, and Icon modes.
- Use consistent icon-only Build, Run, Build + Run, and Custom action controls
  with matching icon sizes, button backgrounds, and name tooltips.
- Explain status badges on hover, including which action last succeeded, failed,
  or stopped.
- Expose Stop directly on app cards in every mode, including parallel actions.
- Restore live Windows theme tracking when switching back to System.
